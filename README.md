# NERP official binary releases

Official distribution-only repository for NERP, maintained by HAT Inc.
The product source is maintained privately. This repository does not contain it.

Anyone may download and retain official binaries. Execution and product use
require an applicable individual agreement; a public download is not a free
trial or an open-source product license. Third-party components retain their
respective rights. See [LICENSE](LICENSE).

## Downloads

[Official releases](https://github.com/neo-erp/nerp-releases/releases/latest)

No official binary is published by the creation of this repository. A release
appears only after the private owner accepts the complete product and verifies
anonymous downloads. No empty or partial release is advertised as installable.

Initial packaging target: Linux x86_64. Each actual release must state its tested
OS, architecture, runtime requirements and exact acceptance scope. Other
platforms are not implied. Public HAT extensions are distributed separately.

Stable asset names:

- `nerp-linux-x86_64.tar.gz`
- `release-manifest.json`
- `SHA256SUMS`

Resolve latest once, then download all files from that exact version tag.
Never mix an archive with checksums fetched from a later latest release.
See [RELEASING.md](RELEASING.md) for the owner and publication boundaries.
